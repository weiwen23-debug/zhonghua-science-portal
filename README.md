Zhonghua Science Portal — Float or Sink prototype

Upload index.html and zhonghua-banner.webp to the root of your GitHub Pages repository. Both files must be uploaded together.

This version includes a uniform-themed illustrated landing banner, seven P3 materials, shape and size controls, predictions, animated tests, observation records, comparison prompts and CSV export. Results remain in the browser and are NOT submitted to Google Sheets. Use fictional student names for testing.

Scientific note: These are simplified illustrative outcomes for specific objects. Shape/air volume can affect buoyancy, and size alone does not determine float/sink for a homogeneous object. The dense-plastic block represents a plastic denser than water. Do not generalise these results to all objects of the same material.
